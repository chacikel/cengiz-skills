## Wichtigste Punkte (Kurzfassung)

### Ordnerstruktur pro Projekt
```
JJJJ-MM_[Thema]/
├── 01_Eingehende-Nachrichten/      # E-Mails, PDFs empfangen
├── 02_Ausgehende-Nachrichten/      # Entwürfe, versendete E-Mails
├── 03_Dokumenten/                  # Verträge, Berichte, Noten, etc.
│   ├── Verträge/
│   ├── Verzeichnisse/
│   ├── Analyseergebnisse/
│   ├── Notizen/
│   └── Sonstiges/
├── 04_Backups/                     # Archivversionen, ZIPs
├── README.md                       # Projektübersicht (zentral!)
└── NOTIZEN.md                      # Interne Arbeitsnotizen
```

### Benennungskonvention
- **Projektordner:** `2026-09_Agentur-Mustermann`
- **Dateien:** `2026-09-20_Mustermann_Vertrag.pdf`
- **Gmail-Label:** `[Kleine-Projekte] → Agentur-Mustermann`

### Workflow
1. Ordnerstruktur erstellen
2. E-Mails archivieren (01 & 02)
3. Dokumente sortieren (03)
4. README.md ausfüllen
5. Zu Google Drive hochladen
