# Table-1-/Baseline-Standards

Quelle: PMC6773463 (Leitlinien zur Erstellung von „Table 1" in epidemiologischer
und klinischer Forschung).

## Zweck von Table 1

Table 1 dient dazu, dass Lesende die **interne und externe Validität** der
Studie einschätzen können — nicht dazu, Gruppen „auf Signifikanz" zu
vergleichen.

## Kernregeln

1. **Keine p-Werte für den Gruppenvergleich in der Baseline-Tabelle.**
   - Statistische Signifikanz ist für Confounder-Beurteilung ungeeignet:
     Nicht-Signifikanz bedeutet nicht „kein Unterschied", Signifikanz bei
     großem n bedeutet nicht „klinisch relevant".
   - Ausnahme: Der Nutzer verlangt explizit einen Signifikanztest (z. B. als
     Sekundärinformation) — dann klar als solchen kennzeichnen und **nicht**
     als Grundlage für Confounder-Auswahl verwenden.
2. **Stratifizieren, nicht mischen.**
   - Kohorten-/RCT-Design: nach Exposition/Behandlungsarm stratifizieren.
   - Fall-Kontroll-Design: nach Krankheitsstatus stratifizieren.
   - Eine **Gesamt-Spalte** ergänzen, damit externe Validität beurteilbar ist.
3. **Variablen so zeigen, wie sie analysiert wurden.**
   Wurde eine Variable im Modell als kategorial (z. B. Tertile) verwendet,
   dann auch in Table 1 kategorial zeigen — nicht die Rohvariable.
4. **Format je Variablentyp:**
   - Kategorial: n (%)
   - Stetig, ~normalverteilt: Mittelwert (SD)
   - Stetig, schief oder mit Ausreißern: Median (IQR bzw. Q1–Q3)
5. **Rundung:** Prozentsätze auf ganze Zahlen runden (z. B. 73,1 % → 73 %).
   Mehr Nachkommastellen nur, wenn es das Verständnis wirklich verbessert
   *und* durch eine große Fallzahl gedeckt ist.
6. **Keine leeren Zellen.** Absichtliche Auslassung durch „—" oder Schattierung
   kennzeichnen, nicht einfach freilassen.
7. **Lesbarkeit vor Vollständigkeit.** Lieber eine fokussierte Tabelle mit den
   wirklich relevanten Variablen als eine erschöpfende Tabelle, die
   unübersichtlich wird. Sekundäre Variablen ggf. in eine Zusatztabelle
   (Supplement) auslagern.

## Prüf-Checkliste vor Abgabe

- [ ] Kein p-Wert-Spaltenvergleich in der reinen Baseline-Tabelle
- [ ] Stratifizierung passt zum Studiendesign (Kohorte/RCT vs. Fall-Kontroll)
- [ ] Gesamt-Spalte vorhanden
- [ ] Format je Variablentyp korrekt (n (%) / Mittelwert (SD) / Median (IQR))
- [ ] Prozentsätze auf ganze Zahl gerundet
- [ ] Keine leeren, unbeschrifteten Zellen
- [ ] Tabelle bleibt auf einer Seite lesbar (ggf. Supplement für Details)
